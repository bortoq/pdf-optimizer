# pdfopt

Оптимизатор PDF. Из нескольких кодировщиков выбирает наименьший **проверенный**
результат и атомарно заменяет исходный файл — только если он стал меньше.

- **Без потерь (по умолчанию)** — картинки и текст остаются пиксель-в-пиксель.
- **С потерями (`-q N`)** — сжимает фото и сканы, пока SSIM каждой страницы
  не ниже `N/100`.

## Установка

```sh
pip install -e .            # pikepdf, pypdf, Pillow, numpy, fontTools, mozjpeg + сборка ECT
pip install -e '.[dev]'     # + pytest, ruff
```

Нужен Python ≥ 3.11 и компиляторы C/C++ (модуль ECT собирается при установке).
Если пакет запускается прямо из каталога с исходниками (без `pip install`),
соберите модуль вручную: `python3 setup.py build_ext --inplace`.
Внешние программы — см. [таблицу ниже](#внешние-программы).

## Использование

```sh
pdfopt book.pdf                      # без потерь
pdfopt -q 96 book.pdf                # с потерями, SSIM страницы ≥ 0,96
pdfopt --dry-run -r /path/to/books   # оценка экономии по каталогу с подпапками
pdfopt -v *.pdf                      # подробный лог
pdfopt --decrypt locked.pdf          # файл с шифрованием без пароля
python3 -m pdfopt --help
```

| Аргумент | Описание |
| --- | --- |
| `-q`, `--quality N` | минимальный SSIM страницы `N/100` (1–100); включает режим с потерями |
| `--dry-run` | посчитать результат, не заменяя исходник |
| `-r`, `--recursive` | обрабатывать PDF в подпапках |
| `-v`, `--verbose` | результат по каждому файлу; в stderr: размер и причина отказа по каждому движку, время, предупреждения об отсутствующих программах |
| `--decrypt` | снять шифрование с файлов, открывающихся без пароля, и оптимизировать их (ограничения владельца — печать, копирование — пропадают) |
| `--force` | обработать файл, даже если он уже оптимизирован |
| `--safe-text` | при `-q` кодировать маску текста без символьного режима JBIG2 (крупнее, но без подмены похожих букв) |
| `--mrc-quality N` | минимальный SSIM текстовых страниц MRC (по умолчанию на 6 ниже `-q`; при `-q 100` — 100) |

**Коды возврата:** `0` — успех (включая «без изменений» и пропущенные файлы),
`1` — хотя бы один файл не удалось обработать, `2` — ошибка аргументов.
Без `-v` в терминале виден индикатор прогресса с долей сэкономленного, а в конце одна строка
итога. Подписанные PDF и файлы с паролем **пропускаются** (`пропущен: …`), это не ошибка;
зашифрованные без пароля обрабатываются только с `--decrypt`.

## Что делает

### Без потерь

Один разбор файла, несколько проходов, одно сохранение:

1. выбрасывает миниатюры страниц, склеивает одинаковые потоки;
2. картинки: RGB, где R=G=B, становится DeviceGray; чисто чёрно-белые 8-битные —
   1-битными; Flate-картинки получают лучший PNG-предиктор; 1-битные Flate и
   CCITT Group 4 переписываются в **JBIG2 generic** (без потерь, обычно на
   30–50 % меньше G4);
3. JPEG: `jpegtran` из mozjpeg (оптимизированные таблицы Хаффмана, подобранные
   прогрессивные сканы; пакет `mozjpeg-lossless-optimization`) с проверкой
   идентичности пикселей — на 0,7–28 % меньше `jpegtran` из libjpeg;
4. встроенные шрифты TrueType урезаются до глифов, которые документ показывает
   (fontTools; номера глифов сохраняются, content stream не меняется): Office
   часто встраивает шрифт целиком — 329 КБ Calibri ради нескольких символов.
   Страницы с изменёнными шрифтами сверяются попиксельно; при AcroForm и любой
   неясности в использовании шрифта он не трогается;
5. потоки пересжимаются встроенным компрессором ECT (как `ect -9`; потоки больше
   4 МБ — как `ect -6`, в 4–8 раз быстрее и на 0,03–0,3 % крупнее; исходники в
   `pdfopt/_ect`), затем сохраняются как object/xref streams (qpdf внутри
   pikepdf).

Метаданные, текстовый слой, геометрия и аннотации не меняются.

### С потерями (`-q`)

Поверх результата без потерь пробуются:

- **MRC** для сканов (страница = одна картинка): фон без текста в 50–100 dpi
  (JPEG или JPEG 2000, качество подбирается по SSIM), маска текста
  в полном разрешении (JBIG2 с общими словарями по 64 страницы, Group 4 или
  Flate), цвет текста — один на страницу, отдельная маска на каждую краску
  (как цвета символов в DjVu) или маленькая цветная картинка под маской.
  Бинаризация адаптивная (блёклые сканы, светлый текст на тёмном), края букв
  сглаживаются, одиночные точки удаляются, пустые страницы схлопываются в фон.
  По размеру не уступает DjVu (`cjb2 -lossy` + IW44) при том же качестве.

  Порог совпадения символов JBIG2 зависит от размера букв в пикселях и
  выбирается для каждой полосы строк отдельно: 0,80 для обычного текста,
  0,85–0,90 для мелкого, а совсем мелкий (около 3,5 pt при 300 dpi или 7 pt
  при 150 dpi) кодируется без потерь. На 4–5 pt порог 0,80 путает 6 и 8, как
  сканеры Xerox в 2013 году, а на самом мелком тексте 9 и 8 путаются даже при
  0,92 (это значение jbig2enc по умолчанию); сноски и подписи под обычным
  текстом поэтому кодируются отдельной маской.

  Текстовые страницы MRC проверяются по порогу `--mrc-quality` (по умолчанию
  `-q` − 6): 1-битная маска не передаёт мягкие края букв скана, и SSIM такой
  страницы не превышает ~0,95 даже при идеальном фоне — без послабления MRC
  при `-q 96` не срабатывал вовсе. Страница считается текстовой, только если
  каждый её фрагмент с чернилами (128 px) теряет на маске не больше 0,15 SSIM;
  фотографии, которые маска огрубила бы, держатся основного порога.
- **JPEG** для остальных фото: поиск наименьшего JPEG (и наименьшего dpi — по
  геометрии из content stream), проходящего SSIM. Flate-фотографии
  переводятся в JPEG.
- **Ghostscript** (профили 300/240/200 dpi) — для PDF без текста (ни одного
  текстового объекта на страницах и в их формах) и без интерактива.
- **Hyper Compress** — внешний `hpdf-worker`, если он найден.

## Как проверяется результат

Кандидаты сортируются по размеру и проверяются от меньшего к большему; берётся
первый прошедший проверку.

| Проверка | Когда |
| --- | --- |
| число страниц, MediaBox/CropBox, поворот, число аннотаций | всегда |
| байт-в-байт content stream каждой страницы (иначе — сравнение текста) | без потерь |
| метаданные (Info и XMP) | без потерь |
| пиксельное совпадение отрисовки (100 dpi) изменённых страниц | без потерь, если менялись картинки |
| SSIM отрисовки (200 dpi, `pdftoppm`) ≥ порога | с потерями: каждая страница MRC и каждая страница с перекодированной картинкой (не прошедшие откатываются к исходной картинке), все страницы — для Ghostscript/Hyper |

SSIM считается в процессе (numpy) по формуле FFmpeg `ssim`, поэтому `ffmpeg` не
нужен. Страницы MRC, не прошедшие порог, возвращаются к исходной картинке.

## Повторные запуски

После успешной оптимизации в каталог документа (`/Root /PdfOpt`) пишется метка.
Повторный запуск пропускает файл (`уже оптимизирован`), а после lossy — не
пережимает его ещё раз (иначе качество падало бы с каждым запуском).
`--force` обходит метку. Файл, который не удалось уменьшить, метку не
получает.

## Внешние программы

| Программа | Нужна для | Без неё |
| --- | --- | --- |
| `pdftoppm` (poppler) | проверка отрисовки, **обязательна для `-q`** | в lossless преобразования картинок отключаются; `-q` недоступен |
| `jbig2` (jbig2enc) | JBIG2: generic в lossless, символьные словари в MRC | Group 4/Flate |
| `opj_compress` (OpenJPEG) | JPEG 2000 фон в MRC | только JPEG |
| `cjpeg` из mozjpeg | более плотный JPEG | Pillow/libjpeg |
| `gs` (Ghostscript) | профили Ghostscript | пропускаются |
| `hpdf-worker` (в `PATH`) | движок Hyper Compress | пропускается с предупреждением |

`hpdf-worker` ищется в `PATH`; если его нет, Hyper Compress не используется,
о чём выводится предупреждение. Все ядра используются автоматически.

## Устройство

```
pdfopt/
  cli.py        аргументы, обход файлов, параллелизм по файлам
  optimize.py   оркестратор: этапы, кандидаты, проверка, метка, атомарная замена
  lossless.py   проходы без потерь (структура, картинки, JPEG, ECT, сохранение)
  _ect/         исходники ECT (Deflate) и биндинг для Python
  jpegopt.py    lossy-перекодирование фото: dpi из геометрии, бисекция качества
  mrc.py        слойное сжатие сканов
  pdfmodel.py   чтение: подпись, отпечаток страниц, метка, обход картинок
  imagedata.py  декодирование картинок, PNG-предикторы, Group 4, размытие
  render.py     pdftoppm, VisualGate (SSIM) и проверка идентичности
  ssim.py       SSIM, совпадающий с ffmpeg
  tools.py      поиск внешних программ, единая обёртка subprocess
```

Подробности и принятые решения — в [docs/architecture.md](docs/architecture.md).

## Тесты

```sh
python -m unittest discover -s tests -t .   # или: pytest
ruff check .
```

CI гоняет тесты на Linux, macOS и Windows (Poppler, Ghostscript и ffmpeg ставятся
пакетными менеджерами; тесты, которым нужен jbig2enc или OpenJPEG, там
пропускаются). Модуль ECT собирается и под MSVC; если сборка не удалась,
установка не ломается — потоки сжимаются zlib.

Тесты, которым нужны `pdftoppm`, `jbig2`, `ffmpeg`, `gs`, пропускаются,
если программы не установлены.
