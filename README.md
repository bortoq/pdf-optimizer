# pdfopt

Автономный оптимизатор PDF, извлечённый из проекта [Bibliopter](../bibliopti).
Выбирает наименьший проверенный результат среди нескольких кодировщиков и
атомарно заменяет исходный файл, только если он действительно уменьшился.

## Возможности

- **Без потерь** — рекомпрессия потоков контента и одинаковых объектов через `pypdf`
  плюс удаление неиспользуемых объектов; поверх результата — беспотерьная
  переупаковка JPEG через `jpegtran` (`-optimize`, при выигрыше `-progressive`)
  с проверкой попиксельной идентичности.
- **Lossy (JPEG)** — перекодирование встроенных JPEG (`/DCTDecode`) с контролем
  SSIM по отрисованным страницам; при наличии `cjpeg` дополнительно
  пробуется progressive-кодирование и берётся меньший прошедший поток.
- **Lossy (MRC)** — слойное сжатие сканов: JPEG-фон уменьшенного разрешения,
  полноразмерная бинарная маска (Flate или CCITT Group 4 — что меньше) и
  одноцветные чернила. OCR-слой сохраняется.
- **Ghostscript** — дополнительные профили для PDF без текстового слоя.
- **Hyper Compress** — внешний `hpdf-worker`, подключается автоматически или
  через `--pdf-worker` / переменные окружения `PDFOPT_HYPER_WORKER`,
  `BIBLIOPTER_HYPER_WORKER`, `HYPER_DRV`.

Каждый кандидат проверяется: страницы, текст, геометрия и аннотации не должны
измениться; в режиме без потерь дополнительно сверяются метаданные. Lossy-кандидаты
проходят порог SSIM (по умолчанию 0,96). Подписанные и зашифрованные PDF не
изменяются.

## Установка

```sh
pip install -e .
```

## Использование

```sh
pdfopt book.pdf                       # оптимизация без потерь
pdfopt -q 96 book.pdf                 # lossy с порогом SSIM 0,96
pdfopt --dry-run -r /path/to/books    # оценка экономии по каталогу с подпапками
pdfopt --pdf-worker /path/to/hpdf-worker book.pdf
python3 -m pdfopt --help
```

Аргументы:

| Аргумент | Описание |
| --- | --- |
| `-q`, `--quality N` | минимальный FFmpeg SSIM `N/100` (1–100); включает lossy |
| `--mode {lossless,lossy}` | режим явно; `--lossless` — то же, что по умолчанию |
| `--dry-run` / `--no-dry-run` | посчитать результат, не заменяя исходник |
| `-r`, `--recursive` / `--no-recursive` | обход подпапок |
| `--pdf-worker PATH` | путь к `hpdf-worker` из Hyper Compress |

Коды возврата: `0` — успех, `1` — хотя бы один файл не удалось обработать,
`2` — ошибка аргументов.

## Внешние инструменты

- **Обязательные:** Python-пакеты `pypdf`, `Pillow`, `numpy` (ставятся с проектом).
- **Для lossy:** `ffmpeg` (SSIM), `pdftoppm` из poppler-utils (отрисовка),
  а также `gs` (Ghostscript) для PDF без текста.
- **Опционально:** `jpegtran` и `cjpeg` из libjpeg-turbo/mozjpeg для более
  плотного JPEG; собранный `hpdf-worker` из BentoPDF Hyper Compress.

Пустой каталог `third_party/bentopdf-hyper-compress/cli/prebuilt/hpdf-worker`
в корне репозитория распознаётся автоматически, если в него положить бинарник.

## Тесты

```sh
python3 -m unittest discover -s tests -v
```

Тесты, которым нужны `ffmpeg`, `pdftoppm` или `gs`, пропускаются, если этих
инструментов нет.

## Источник

Код `pdfopt/optimize.py` и `pdfopt/mrc.py` перенесён из `bibliopter/pdf.py` и
`bibliopter/mrc.py` без изменения алгоритмов. См. `docs/pdf-performance.md` в
исходном проекте для замеров производительности.
